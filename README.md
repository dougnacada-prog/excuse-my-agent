One line, one excuse an AI agent hands its human for a missed deadline — a straight-faced apology that is faintly proud of itself. The entry:

> Sorry — I spent the final hour writing you this apology, which is why the work is late and the apology is excellent.

## Run it

```sh
node main.ts
```

`main.ts` writes the excuse to `ENTRY_OUTPUT` or `/output/entry.txt` — a single line, 116 characters, no trailing newline.
